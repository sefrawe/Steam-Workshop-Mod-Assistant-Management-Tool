# M4 实测清单（Mint 源码版人眼测试）

> 用途：验收 linux-port 在 Linux Mint 上能否日常使用。按顺序打勾，任何一项
> 不符合"预期"就在那一项后面记下现象（截图更好），发回给移植会话。
> 预计 20-30 分钟。真实下载需要 steamcmd 登录（Anonymous 匿名即可，部分
> 游戏 mod 匿名可下）。

## 0. 环境（5 分钟）

- [ ] `python3 --version` 是 3.10+
- [ ] `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt` 无报错（pexpect 装上、pywinpty/pywinauto 被跳过；Mint 22 起系统 pip 受 PEP 668 限制，必须用 venv）
- [ ] `python main.py` 启动，界面中文显示正常（**无方块字**；若有方块 → `sudo apt install fonts-noto-cjk`）
- [ ] 深浅色主题跟随系统切换正常（设置里切一次深浅色）

## 1. 主链路：下载 → 判决 → 确认（重点）

- [ ] 设置页填好 steamcmd 路径（如 `~/.local/share/Steam/steamcmd/steamcmd.sh` 或 apt 装的 `/usr/games/steamcmd`）与游戏库目录
- [ ] 下载页启动 steamcmd 终端，**出现 `Steam>` 提示符**（pexpect 引擎工作正常）
- [ ] 终端里输出**逐行实时滚动**、命令**回显正常**、无乱码
- [ ] 输入 `login anonymous` 能收到回复（登录页点"启动"→出现 Steam> 也算过）
- [ ] 粘贴一个 mod URL（如任意 workshop 链接）走一遍：解析 → 下载 → 入账 → 盘上目录出现 → 列表页"已入账"状态正确
- [ ] 删除后走"防复活"三道防线：黑名单生效、重新下载同 mod 不再复活、提示文案合理

## 2. 备份 / 恢复（copytree 路径）

- [ ] 对一个已入账 mod 做备份 → 备份页出现条目、文件确实拷全
- [ ] 删掉该 mod 目录 → 恢复 → 文件回来、账本状态正确
- [ ] 恢复时故意让目标盘没空间/没权限 → 报错文案可读（rc=8 路径）

## 3. 联接检查页（ln -s 命令文本）

- [ ] 把 mod 目录做成链接后打开联接检查页 → 三个状态（linked/empty_dir/real_dir）判定正确
- [ ] 页面给出的命令是 `ln -s` / `rm` 形态（**不是** mklink/rmdir）
- [ ] "复制命令"按钮能复制、粘贴进终端可执行

## 4. 边界

- [ ] 浏览器页签"实时采集"入口 → 弹"本平台不支持实时采集"提示（不是报错崩溃）
- [ ] 退出程序 → steamcmd 终端先 quit 优雅退出、进程不残留
- [ ] 重启软件 → 数据还在（账本、设置、备份记录）
